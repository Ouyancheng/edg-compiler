# Front End Documentation

The front end documentation is generated by
[Sphinx](https://www.sphinx-doc.org).

## Installation

```
pip3 install -U Sphinx shibuya
```

If `pip3` is not an alias for Python 3's PIP, use:

```
pip install -U Sphinx shibuya
```

## Make HTML

To make an HTML version of the documentation, after Sphinx is installed:

```
cd doc-sphinx
make html
```

These files can then be viewed in the browser by opening
`build/html/index.html`.
